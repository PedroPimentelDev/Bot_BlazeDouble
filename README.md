# Bot_BlazeDouble

## Descrição
🎲BlazeBot: Automatize suas apostas com este bot inteligente! Receba alertas e oportunidades de entrada para dobrar suas apostas na casa de apostas Blaze, diretamente no seu Telegram. 🤖💰 

## Funcionalidades
- O bot sugere entradas e estratégias para o jogo "Double" na plataforma Blaze.
- Histórico de entradas.
- Alertas e notificações.
- Estatística completa sobre assertividade e lucro.

## Pré-requisitos
- Python 3.
